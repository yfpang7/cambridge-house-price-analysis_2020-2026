# Cambridge house price analysis, 2020-2026

Exploratory analysis of UK Land Registry Price Paid Data for Cambridge, Royston, Saffron Walden and Stevenage: has a Cambridge flat lost value, when to sell, and what a 2-3 bed freehold house would cost.
